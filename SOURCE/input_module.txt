=============================================================================

BIGGEST ARCHITECTURE CHANGE

The operational map is no longer made only of Locations.

The map now consists of five different node types.

1. L = Operational Locations
2. CP = Checkpoints
3. RP = Rest Points
4. HP = Helipads
5. J = Junctions

This creates a complete operational road network instead of a simple location map.

• Connect multiple roads
• Improve graph traversal

• Reduce routing complexity
• Build an actual road network

Users NEVER select Junctions.
